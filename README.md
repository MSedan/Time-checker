This is an application, which takes user input for the start time and end time and checks if it was inputted in the correct format. 
The acceptable time formats are based on the 24h clock and 15-minute intervals(HH:00, HH:15, HH:30, HH:45). If the user enters a time in incorrect format, the application will give feedback and exit. 

Edge cases:
 - 24:00 
   
 - 9:00

What happens if the end time and Start time are the same.
